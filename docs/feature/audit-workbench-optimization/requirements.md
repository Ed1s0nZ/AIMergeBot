# 语言无关、跨仓库PR增量审计优化需求

- Status: Confirmed
- 日期：2026-10-06；快照：R3
- 来源：用户要求调研论文、成熟开源项目并优化工具、功能、页面；明确不限制语言、可以跨项目；进一步明确本项目基于PR。
- 确认人：本聊天用户；确认日期：2026-10-06；确认消息：“确认”。

## 目标

以固定BASE/HEAD和PR diff为调查起点，识别本次改动新增、暴露或加剧的风险，包括删除保护条件和破坏跨项目契约。按需追踪未修改文件及授权上下文仓库，增强反证检查与人工复核，降低重复读取成本。全仓库搜索是取证手段，不是默认全项目漏洞扫描任务。研究证据见research.md及deepaudit-comparison.md。旧草案仅覆盖复核和效率，本快照扩展为完整优化目标；任何单阶段完成均不代表全部目标完成。本快照及默认选择已由用户确认，优先级均为Unprioritized。

## 已确认假设与默认选择

- ASM-001：默认只读，不自动编译或执行仓库代码及模型生成脚本；语言分析器、向量检索和运行时验证为可选增强。
- ASM-002：跨项目指一次PR调查关联已授权仓库和固定提交，结论归属主PR；跨托管平台自动发现及新账号接入需另定义场景和授权。
- ASM-003：复核写入统一要求版本条件，缺失条件明确报错；保留读取兼容，但不保留无条件覆盖。此选择与旧草案不同，交付要记录调用方迁移。
- ASM-004：分阶段实现全部确认需求，沿用现有界面风格，先优化信息组织、状态及可访问性；不强制引入动态Agent或向量数据库。
- ASM-005：交付源码、文档、测试和分支，不自动合并或部署；真实模型质量评测记录样本、模型与成本，外部条件缺失时明确未验证，不能以模拟测试代替准确率证据。

## 失败与恢复

可选工具、检索或网络失败明确显示原因和覆盖缺口，允许回退文本调查。权限每次核查；索引与缓存按仓库及提交隔离。复核冲突不自动重发覆盖，导出不自动上传。中断任务从持久化状态恢复，未完成不得显示为无风险。
