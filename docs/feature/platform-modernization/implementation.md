## 交付边界

新运行由 internal/platform 独立承担：认证/配置/数据库/HTTP/任务编排/GitLab/Eino/证据验证。保留旧模块用于历史类型和对照测试，不再注册旧业务路由。React 页面拆分为登录、概览、项目、任务列表/详情、用户、系统设置、事件；Go 二进制嵌入构建产物。

身份使用 bcrypt 和数据库中哈希后的随机会话令牌，角色在服务端检查，用户禁用/改密/改角色撤销会话。首次管理员仅从明确环境变量引导。设置保存原子写入工作目录 config.yaml，权限 0600；敏感字段在返回中清空，空输入保留原密钥。项目 API 同步 projects 与 enabled。执行捕获配置快照，模型/仓库变更不会使正在运行的审计混用配置；listen/worker 变更提示重启。

MR 快照固定 base/head/source project 和 GitLab diff version ID，版本分页查找并校验返回 refs。新增与删除行分别用 head/base 证据，支持 fork 与重命名。Eino v0.9.21/openai extension v0.1.13 使用标准工具调用，三种只读工具共享预算/缓存/取消上下文。严格 JSON、真实行证据与去重验证代替文本兜底；截断/失败/超时明确影响状态。工具详情记录调用及可用模型 usage，不存原始思维链。

SQLite 持久化任务、复核与事件；统一手动/Webhook/轮询入口；事务与活动唯一键实现并发去重，重审保留历史。worker/超时/取消有界，重启中断标记失败。评论默认关闭，发送前确认 head，网络结果不确定时不自动重复。旧结果幂等导入为 incomplete，原表保持；旧 MR 级复核仅保存在原表，无法可靠映射到具体候选时不伪造。
