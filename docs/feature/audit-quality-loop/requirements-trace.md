# F1 需求承接

本文件不是新需求确认快照。权威已确认需求仍为 ../audit-workbench-optimization/requirements.md R3；当前“最佳实践优化”继续授权这些目标。新增实现选择按保守假设记录，不称用户逐项批准了新文档。

- AC003/005：重要假设记录必须检查的输入、PR因果、保护条件、相关契约以及未完成项；来源和跨组边界保持。
- AC006：独立支持按输入可控、PR因果、保护/反证、有害结果四项留下新来源判断；任一缺失/不支持不得整体supported。仍是静态模型判断，不是运行证明。
- AC007：展示分项判断与具体缺口，历史缺少新字段不回填或伪装通过。
- AC011：使用既有失败作回归，新增冻结验收与真实历史PR来源/真值必须独立核查，不能将生成样本叫真实PR。跟踪准确性、证据和成本，保留失败。
- AC012：可选字段兼容旧读取，门禁变化升级policy；授权、新源、取消/恢复与预算不削弱。

验收：缺项/重复/非法判断/非新来源不能支持；四项齐全且新来源有效可保留条件支持；主锚点与跨仓库门禁仍成立；UI显示每项与证据；真实模型复核检查是否实际填写，不仅用模拟证明语义质量。

后续仍需调查计划、结构化覆盖、风险调度及存储开销的证据与收益核对，只有有测量依据才宣称性能改善。无语言解析器准入限制、无自动执行/部署。
